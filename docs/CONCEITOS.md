# Mapa de conceitos

Este mapa indica o que observar em cada trilha. Os arquivos continuam sendo
exemplos práticos; o objetivo é usar esta página para escolher uma revisão.

| Trilha | Conceitos principais |
| --- | --- |
| `01-fundamentos` | tipos, variáveis, coerção, operadores, strings, f-strings, `input`, `if`/`elif`/`else`, identidade e precisão de ponto flutuante |
| `02-controle-de-fluxo` | `while`, `for`, `range`, contadores, laços aninhados, `break`, `continue` e `else` em laços |
| `03-colecoes` | listas, slicing, métodos, dicionários, conjuntos, desempacotamento, comprehensions, cópia rasa/profunda e `itertools` |
| `04-funcoes` | parâmetros, `*args`, `**kwargs`, escopo, closures, funções de ordem superior, `lambda` e decoradores |
| `05-excecoes` | `try`, `except`, `else`, `finally`, `raise` e validação de entradas |
| `06-modulos` | importação, modularização, cache de módulos e organização em pacotes |
| `07-outros` | experimentos, revisões e exemplos que cruzam mais de um tema |

Os exercícios repetem e combinam esses conceitos:

- `01-fundamentos`: lógica e operações básicas;
- `02-controle-de-fluxo`: jogos e problemas iterativos;
- `03-colecoes`: transformação, busca e organização de dados;
- `04-funcoes`: abstração, reutilização e validação;
- `05-projetos`: programas maiores para consolidar o conteúdo;
- `06-integracoes`: arquivos, APIs, regex e tarefas agendadas.

## Como ler os exemplos

1. Identifique as entradas e o tipo de cada valor.
2. Siga o fluxo linha a linha, anotando mudanças nas variáveis.
3. Observe a estrutura de dados usada e por que ela foi escolhida.
4. Execute um caso normal e um caso-limite.
5. Reescreva uma parte como função para testar seu entendimento.
