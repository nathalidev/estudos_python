# Exercícios

Use esta pasta depois de estudar uma aula. Tente resolver o problema sem olhar
o arquivo de referência e só depois compare estratégias.

Os exercícios estão separados em fundamentos, controle de fluxo, coleções,
funções, projetos e integrações. Os arquivos podem ter níveis diferentes de
acabamento: isso faz parte do histórico de aprendizagem.
